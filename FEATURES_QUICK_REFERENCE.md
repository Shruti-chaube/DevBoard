# DevBoard - Quick Reference Card 🚀

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl+K` / `Cmd+K` | Quick Add Task |

---

## 🎯 Task Actions

### On Every Task Card

| Icon | Action | Description |
|------|--------|-------------|
| ← | Move Left | Move to previous column |
| → | Move Right | Move to next column |
| ✏️ | Edit | Edit task details |
| 📋 | Duplicate | Create a copy |
| 📦 | Archive | Archive (Done tasks only) |
| 🗑️ | Delete | Remove task permanently |

---

## 🔍 Search & Filter

### Search
- Type in search box
- Searches title AND description
- Case-insensitive
- Click ✕ to clear

### Filter by Priority
- All Priorities
- High Priority
- Medium Priority
- Low Priority

### Sort By
- Newest First
- Oldest First
- Priority: High to Low
- Priority: Low to High
- Due Date

## 📅 Due Dates

### Display Format
- **Today** - Due today
- **Tomorrow** - Due tomorrow
- **Jan 15, 2024** - Other dates

### Visual Cues
- 📅 Gray = Upcoming
- 🔴 Red = Overdue

## 💡 Quick Tips

### Fastest Way to Add Task
```
Press Ctrl+K → Type title → Set priority → Click Add
```

### Keep Board Clean
```
Move tasks to Done → Click Archive button
```

### Find Tasks Fast
```
Type in search → Filter by priority → Sort by due date
```

### Duplicate Similar Tasks
```
Click duplicate icon → Edit title → Done!
```

## 🆘 Troubleshooting

### Can't Find a Task
✅ Clear search and filters
✅ Check other columns
✅ Check if archived

### Empty Column
✅ Check active filters
✅ Look at "X/Y" counter
✅ Try "Clear All Filters"

### Date Picker Not Working
✅ Click the date input
✅ Can't select past dates (by design)
✅ Use arrow keys to navigate
